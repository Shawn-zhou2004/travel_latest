# Guide and Trip Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver weather-aware preparation lists, budget summaries, image recognition support, foreground companion sessions, sourced POI narration, CosyVoice audio, subtitles, and safe playback controls.

**Architecture:** Guide features depend on itinerary/map/media contracts but own guide sessions, narration cache, sources, and play events. Location is used only in the active foreground session; continuous location history is not persisted.

**Tech Stack:** FastAPI, SQLAlchemy, Redis, RabbitMQ, AMap, Qwen-VL/Qwen search, CosyVoice, OSS, Vue 3, browser Geolocation and Audio APIs, pytest, Vitest.

## Global Constraints

- Requires itinerary intelligence, maps, media upload, and Outbox foundations.
- Continuous user location is never persisted; only current session trigger state and POI play/skip events are stored.
- Narration must display at least one source. Without a reliable source, return only AMap basic information and no invented historical story.
- Guide triggers only after user starts a foreground session and grants location/audio permission; background, revoked permission, and driving mode pause autoplay.
