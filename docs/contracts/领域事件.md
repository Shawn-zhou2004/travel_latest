# Domain Events

All Outbox events use this envelope. The application writes the aggregate mutation and the envelope into `outbox_events` in the same MySQL transaction. Publishers require RabbitMQ confirms; consumers deduplicate by `event_id` or an equivalent domain unique key.

```json
{
  "event_id": "uuid",
  "event_type": "itinerary.generated",
  "aggregate_type": "itinerary",
  "aggregate_id": "uuid",
  "occurred_at": "2026-08-01T00:00:00Z",
  "trace_id": "uuid",
  "payload": {}
}
```

| Field | Contract |
|---|---|
| `event_id` | UUID; immutable globally unique event identity. |
| `event_type` | Stable dotted lowercase noun-past-tense name from the catalog below. |
| `aggregate_type` | Canonical aggregate singular, such as `itinerary`, `post`, `travel_order`, or `payment_record`. |
| `aggregate_id` | UUID public ID of the aggregate whose state changed. |
| `occurred_at` | UTC RFC 3339 time at the committed domain change. |
| `trace_id` | Request or worker trace ID propagated across API, worker, messaging, and provider callbacks. |
| `payload` | Pydantic-validated JSON containing IDs, versions, public state, and consumer-required facts. It excludes secrets, raw tokens, payment signatures, full prompts, continuous locations, and unredacted chat bodies. |

## Event Catalog

| Event type | Aggregate | Required payload fields | Consumers / effect |
|---|---|---|---|
| `itinerary.generated` | `itinerary` | `itinerary_id`, `version_id`, `owner_id`, `status` | Notify owner; prepare eligible search projection. |
| `itinerary.version_created` | `itinerary` | `itinerary_id`, `version_id`, `version_no`, `source` | Collaboration delivery and audit. |
| `itinerary.published` | `itinerary` | `itinerary_id`, `version_id`, `city_code` | Public itinerary search indexing. |
| `itinerary.archived` | `itinerary` | `itinerary_id`, `version_id` | Remove or update public projections. |
| `generation_job.completed` | `generation_job` | `generation_job_id`, `itinerary_id`, `status`, `error_code` | Notify requester and operations. |
| `import_job.completed` | `import_job` | `import_job_id`, `itinerary_id`, `status`, `error_code` | Notify requester. |
| `export_task.requested` | `export_task` | `export_task_id`, `itinerary_id`, `version_id`, `format` | Worker generates export. |
| `export_task.completed` | `export_task` | `export_task_id`, `status`, `asset_id`, `error_code` | Notify requester. |
| `post.published` | `post` | `post_id`, `author_id`, `content_type`, `city_code` | Community search indexing and notifications. |
| `post.hidden` | `post` | `post_id`, `reason_code` | Remove public projection. |
| `companion_application.accepted` | `companion_application` | `application_id`, `request_id`, `conversation_id`, `applicant_id` | Persist notification and establish chat delivery. |
| `message.created` | `conversation` | `conversation_id`, `message_id`, `recipient_ids` | Realtime delivery and unread notification. |
| `travel_search_job.completed` | `travel_search_job` | `travel_search_job_id`, `status`, `offer_count`, `error_code` | Notify requester; no synthetic offers. |
| `travel_order.created` | `travel_order` | `travel_order_id`, `order_no`, `status`, `payment_status`, `fulfillment_status` | Notification and supplier confirmation workflow. |
| `payment_record.paid` | `payment_record` | `payment_record_id`, `travel_order_id`, `amount`, `currency` | Advance order only through its state machine; request fulfillment. |
| `travel_order.fulfillment_updated` | `travel_order` | `travel_order_id`, `status`, `payment_status`, `fulfillment_status`, `failure_code` | Notify owner and update read models. |
| `refund_record.updated` | `refund_record` | `refund_record_id`, `travel_order_id`, `status`, `amount`, `currency` | Notify owner and update order read model. |
| `narration.requested` | `poi_narration` | `poi_id`, `itinerary_id`, `language`, `source_version` | Worker retrieves sources, produces narration, and stores audio privately. |
| `provider.application_updated` | `provider` | `provider_id`, `status`, `reviewer_id` | Notify provider staff and audit. |
| `experience_booking.updated` | `experience_booking` | `booking_id`, `provider_id`, `status`, `travel_order_id` | Provider and customer notification. |
| `membership.entitlement_updated` | `user_membership` | `user_id`, `membership_id`, `status`, `valid_until` | Refresh user entitlement read model. |
| `admin.action_recorded` | `admin_action` | `actor_id`, `action`, `target_type`, `target_id` | Immutable audit and operations feeds. |

Retries never alter `event_id`, `occurred_at`, or `payload`. Administrative replay republishes the original envelope and records replay metadata separately.
