## 服务器启动后的顺序

```bash
docker compose up -d
cd backend
alembic upgrade head
alembic downgrade -1
alembic upgrade head
python -m pytest
```

确认数据库迁移和后端测试后，再启动 API、Worker、消费者前端和管理端，并按部署教程配置 Nginx、域名、HTTPS、备份和安全组。
